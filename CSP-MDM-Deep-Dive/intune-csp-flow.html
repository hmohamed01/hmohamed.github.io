      The seam: Intune is the compliance authority, but the gate lives in Entra. Intune writes isCompliant onto the Entra device object; Conditional Access reads that property at sign-in. So a freshly-fixed device stays blocked until Intune re-evaluates and the directory state syncs. (Hybrid-join CA uses device join state instead of Intune compliance.)

On-prem crosswalk

    
OMA-DM session (poll cadence)≈Group Policy background refresh interval

    
CSP≈Client-side extension (CSE) that applies a policy

    
OMA-URI (LocURI)≈The registry / policy path a GPO writes

    
MDM enrollment cert≈Domain membership — trust that authorizes the channel

    
Entra device object (isCompliant)≈The AD DS computer object + its health attributes

    
Conditional Access (require compliant)≈NPS / NAC posture check gating network access
